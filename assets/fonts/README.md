# Ashes dice symbols

`phg-ashes.woff` / `.woff2` is an icon font with the Ashes magic symbols (power, class and basic
symbols for every dice type), taken from the open-source Ashteki client
(github.com/Ashteki/ashteki, `client/assets/fonts`). The symbols belong to Plaid Hat Games.

Glyphs used by Argaia:

| Symbol | Code point |
|---|---|
| basic (all dice) | U+E800 |
| astral power / class | U+E817 / U+E818 |
| artifice power / class | U+E819 / U+E81A |

Other dice types' code points are in Ashteki's `client/styles/_phg-ashes.scss`.
